Règles de confidentialité

Dernière mise à jour : 11 novembre 2026.

FanDeClip Uploader est un outil personnel utilisé par une seule personne, le propriétaire de la chaîne YouTube sur laquelle il publie. Il n'a pas d'autres utilisateurs.

Services API YouTube

FanDeClip Uploader utilise les Services API YouTube. En l'utilisant, vous acceptez les Conditions d'utilisation de YouTube. Les Règles de confidentialité de Google s'appliquent aux données traitées par Google.

Données Google utilisées

L'outil demande une seule autorisation : https://www.googleapis.com/auth/youtube.upload. Elle sert uniquement à envoyer sur la chaîne du propriétaire les vidéos qu'il a validées (titre, description, tags, date de publication). L'outil ne lit pas les vidéos, commentaires, abonnés ni aucune autre donnée du compte, et n'accède aux données d'aucun autre utilisateur.

Données TikTok utilisées

Pour TikTok, l'outil utilise Login Kit et la Content Posting API avec les autorisations user.info.basic et video.upload. Elles servent uniquement à identifier le compte TikTok du propriétaire et à déposer les vidéos qu'il a validées dans ses brouillons TikTok, où il les publie lui-même depuis l'application TikTok. L'outil ne lit ni les vidéos, ni les abonnés, ni les messages, et n'accède aux données d'aucun autre utilisateur TikTok. L'accès peut être retiré dans l'application TikTok (Paramètres, Sécurité, Applications autorisées). Les Conditions d'utilisation de TikTok s'appliquent.

Stockage et partage

Les jetons d'accès OAuth (Google et TikTok) sont enregistrés uniquement sur l'ordinateur personnel du propriétaire. Ils ne sont envoyés à aucun serveur tiers, ni partagés, vendus ou utilisés à des fins publicitaires. L'outil n'utilise pas de cookies.

Suppression et révocation

L'accès peut être retiré à tout moment depuis la page des paramètres de sécurité Google : security.google.com/settings/security/permissions. Le jeton local est alors inutilisable. Pour faire supprimer toute donnée stockée par l'outil, écrire à l'adresse ci-dessous : le fichier du jeton est supprimé sous 7 jours. Le jeton est aussi supprimé si l'outil n'est plus utilisé.

Utilisation limitée

L'usage des données reçues des API Google respecte le Règlement sur les données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée.
